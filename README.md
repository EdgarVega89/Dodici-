# Dodici Manager Console — Web V1

Static PWA prepared for Vercel.

## Included
- Persistent guest arrivals using localStorage
- First-time guest / celebration / allergy handoff cards
- Returning / VIP guest profiles
- 86 Center with low-stock / critical / 86 states
- Menu items linked to selected inventory dependencies
- Menu & wine reference screens
- Editable What If? standards and operating targets
- PWA manifest + service worker for iPhone Add to Home Screen / offline shell

## Data model in V1
Data is stored on the individual browser/device.
A later shared version should replace localStorage with Supabase so Host, Servers and Manager share one live data source.
